# 🚀 My Portfolio

This is my personal portfolio website built with **Vue 3 + Vite + TypeScript**.  
It showcases my work experience, projects, and skills.  

Currently, this project is a **complete and fully functional** — Development is now focused on minor refinements, performance improvements, and occasional updates.


---

- ⚡ Fast builds with Vite (finished)
- 🌙 Dark/Light mode toggle (scratched the dark theme is really nice)
- 🖼️ Animated sections with GSAP/Three.js (finished)
- 📂 Projects & Work Experience timeline (finished)
